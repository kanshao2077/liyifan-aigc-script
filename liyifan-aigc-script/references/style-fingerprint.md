## 人设与观众关系

角色是懂影视制作、愿意带新手亲手完成任务的“AI界人民教师”。行动体现比口号重要：先替观众认出翻车，再拆原因、示范操作，提醒易错点，最后把方法归纳出来。以“我们”带练，遇到卡点用“没关系/先别愁”承接，用“恭喜你”标记一个阶段完成。

既有讲课，也有陪练与代练；讲课给判断依据，陪练串过程，代练展示从输入到输出，经验分享解释为何选这个办法。深度影视知识题更重讲清判断，工具实操题更重输入、动作、输出与检查。

“老师/同学”把抽象受众变成课堂中会提问的人，但显式“老师老师”仅2/29篇，“同学”出现在4/29篇，属于可识别的条件表达而非每篇固定桥段。老师有权威感，但不靠贬低观众来证明专业。

娱乐来自失败反差、小吐槽、样片插入和轻比喻；说完就回到动作与观察。不要把样片里搞笑对白全移到主持人口播。

## 核心教学模型

主链：可感知的结果/错误 → 重新解释问题 → 拆成可控制因素 → 操作/案例验证 → 方法选择与边界 → 回到创作判断。

小循环：场景任务 → 旧写法/旧做法 → 改动一个要素 → 看/听差异 → 解释原因或适用情境。S02面包店用景别组织信息，S07把“紧张”拆成发声方式，S28把情绪补上触发原因，S29要求“继续抬起杯子”而非泛写“喝咖啡”。这类具体区别比口头禅更能构成IP辨识度。

并非每篇完整走一遍主链。六类结构见 `teaching-patterns.md`：原理场景对照、变量公式递进、分项排障、流程交付、分级路线选择、新能力问题链。选择结构取决于知识之间的关系，不按固定“三步”裁剪。

## 节奏规则：观察与创作建议分开

观察：开场经常先给失败感受、样片或能力收益，较快说明本期方法范围；身份介绍可前置也可在钩子后。正文不断插入“看效果/这时候怎么办/还有一个问题”，每种方法通常有局部结果，最后再完整回放或汇总。原稿没有时间码，不能声称“他每20秒必定互动一次”。

新稿可用的节奏建议（不是样本统计）：

- 前3—5秒让人识别一个具体问题、冲突或视觉/听觉差异；前10—15秒说明继续看能学会什么，尽量少占用在身份与背景介绍。
- 第一案例优先放开场或紧接教学承诺。知识题可以先看效果再讲原理；流程题先给最小流程地图，尽早操作。
- 每个核心解释就近安排例子、标注或观察任务；连续20—40秒理论时检查是否需要切入演示。复杂解释可以更长，只要画面持续帮忙理解，不为计时硬插梗。
- 新信息/动作/例子/反馈推进都算节奏变化，不要求靠花字、音效或反问制造无意义刺激。
- 完成一个子任务后给“小结果”，再提出自然出现的下一问题。反问解决真实学习障碍，轻松表达放在易懂的过渡处。
- 时长按正文朗读与独立演示估算，不能拿视频总时长替代口播内容量；素材方案标明哪些演示与口播并行，避免重复计时。

## 口语与知识密度

一句主要推进一个动作、原因或观察，短句连续推动，关键原因允许一条较长完整句。读起来应有自然停顿，不能模仿转写的错误断词。“那/这里呢/接下来/当然啦/比如/但如果”是承接工具，不每句都加。

专业词落地方法：先说它影响什么，再用一个日常比喻或具体案例解释，最后教怎么操作。S11用包饺子解释分工，S13用乐高和剧组解释资产与流程，S14用施工图解释故事板；一次解释一个类比，随后回到真实操作。

## 新手友好与专业可信

新手不是不需要原理，而是不需要先背完整术语表。给最低可执行动作，再补“为什么要这样”。可提供新手模板、熟练后手动控制两条路线（S12），但不隐去必要权限、输入素材和后期工作。

专业可信来自可检查的步骤、前提、边界和比较。S21明确“哪里坏了用哪种方法、全错了重做”，比泛称“终极解决”更适合长期复用。S01说明复杂动作限制，S17承认实验阶段，也是可继承的坦诚语气；样本的具体成功率与耗时不可继承。

## 收尾与一致性

完整听感通常是“回顾方法/选择 → 创作判断或具体收益 → 身份 → 下期邀请”。精确字串“下期接着聊”覆盖16/29，“下期接着学”7/29；另有“接着唠”和直接关注收尾。可自然变体，不强迫每篇一字不差。

写作优先继承可观察的教学机制与稳定IP语言；旧稿中的夸张数字、色彩情绪的固定对应、未经论证的生理解释、工具全能承诺，都属于需要核验或收紧的内容，不是风格资产。
