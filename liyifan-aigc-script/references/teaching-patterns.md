# 基于样本的六类教学结构

编号对应 `sample-analysis.md`。以下为主结构人工编码，不表示一篇只使用一种方法。

## T1 原理与场景对照（S02、S10、S24、S26）

模糊质感问题 → 同场景旧版 → 一个影视变量 → 改后对照 → 用人话解释作用 → 换适用场景 → 汇总。

适合景别、光线、色调、运镜等知识。S02先用面包店展示环境—动作—情绪的信息组织；S10同一逆光分别用于英雄、恋人、神秘人物，说明同种手法可能有不同用途。不要压成“某色必然某情绪”的固定定律。重要解释必须点出画面具体变化，避免全靠“是不是更高级”。

## T2 变量公式与递进（S07、S19、S28）

同一句话/同一个问题的差异 → 提取可操作变量 → 分变量示例 → 新手不会写的疑问 → 可复制结构 → 补情境/动机 → 总结与边界。

S07从标点到发声方式再到场景动机；S28从表情、肢体、语气再补情绪原因；S19每类开场都有叙事要素与应用例。所谓公式是经验组织工具，不是假装数学规律或跨模型必然有效。适合表演、音色、运镜动机；确有几个可操作变量才给公式。

## T3 分项排障与条件选择（S03、S09、S15、S16、S21、S25、S27）

具体穿帮 → 分清故障类型 → 每类问题的输入/处理/回看 → 多人或复杂场景扩展 → 选择条件 → 汇总。

S15按人声、音效、音乐分开，并各自给替代路线；S21按问题范围决定修哪里；S27先单人声纹，再用学生问题推进多人绑定。适合声音、修复、一致性。不把不同问题的平行解决法写成必须依次执行的流水线。

## T4 制作流程与完整交付（S04、S05、S06、S08、S11、S13、S20）

成片/可交付结果 → 为什么需要前期规划 → 最小流程图或生活类比 → 一个案例依赖顺序实操 → 节点检查与修改 → 完整结果/交付检查 → 流程价值。

S11明确分镜师交付如何被生成师与剪辑师接用；S08从商品图、方案、人物与场景、分镜走到TVC。适合商业实操、Skill工作流、IP设计。深度来自为何要这份输入、哪步由人判断、失败如何返工，不能只重复“点继续”。不能称该账号从未讲过商品广告或虚拟代言人。

## T5 分级方法与路线选择（S12、S17、S29）

一个共同目标 → 简单可完成的方法 → 它不能满足什么 → 进阶方法 → 复杂任务或前期重构 → 按目标选择。

S12从自动到故事板再到资产手控；S17基础参考、实验性重绘运镜、疏化故事板控制；S29景别角度衔接、动作衔接、从分镜设计连续性。递进须增加控制能力或解决新限制，不能将三个同等技巧硬叫“终极”。

## T6 新能力带出问题链（S01、S14、S18、S22、S23）

新能力/反差 → 具体任务 → 关键原理或职责 → 操作 → 新暴露的问题 → 条件或替代方案 → 汇总可用范围。

S22时间控制后接空间控制、参考串用、成本选择；S14故事板后引出角度与位置、导演台；S18生成建议后进入审片选择；S23用跟随与正反打两个任务验证白模。工具更新先核实，不能照抄历史版本与数字。

## AB与案例制作规则

- 教学比较优先同一句台词、同场景、同一组镜头。分清单变量测试与整套流程比较；后者不能把效果全部归因于一个词。
- 先交代观察点：看杯子是否接着动、听音乐在哪断、看脸是否被背景吞没。对比应有实际差异，不能给完全相同素材伪造AB。
- 计划生成的素材标待生成/待验证，选择案例与预期不等于已经成功。生成不理想时可用失败样本教边界，不伪造成功。
- 给制作者可执行的资产描述、输入、Prompt和观察标准。需要引用电影镜头时给可靠定位，不能只说“放经典电影”；自制示意可作为低成本替代。
- 小例子紧跟知识，最后可合成一个完整案例。观众需要知道学会后怎样独立判断，而不只是抄出一次结果。
