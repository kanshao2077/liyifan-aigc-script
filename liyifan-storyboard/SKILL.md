# 李一帆分镜

把口播变成可执行的后期方案。不要把用户稿件当成不可修改的成品，也不要为了显得专业而重写个人口吻。先判断脚本承诺、案例和演示是否一致，再决定哪些问题由画面与声音解决，哪些需要改口播。

## 输入与边界

最低输入是一版完整或接近完整的口播。可附 Excel 模板、录音、已有画面、参考图、素材文件名、剪辑软件、画幅和目标时长。

- 只有选题或核心观点、还没有完整口播时，优先由可用的 `$liyifan-aigc-script` 完成写稿，再进入本 Skill；即使该 Skill 不可用，也可以先写出完整口播后继续，不让用户重复描述同一任务。
- 用户已确认的选题不重新评审。可以质疑脚本的论证、事实、实验变量和可拍性。
- 不因为用户说“最新版”就默认稿件最优。若稿件中的承诺与实际演示冲突、概念不准确、重复严重或素材无法支持，必须指出并处理。
- 未看到的素材、未完成的实测和未核实的结果，不能写成“已有”“实测有效”或“成片可见”。

## 工作流程

1. **锁定版本与素材事实**
   - 以用户本轮明确提供的全文为当前基准，不再从旧对话猜“最新稿”。
   - 列出已有、待录、待生成、待下载、待核对和需要用户补充的素材。文件名只有在输入或模板中真实出现时才能当作已有。

2. **先审脚本，再拆镜头**
   - 检查开头承诺、核心问题、案例变量、演示顺序、知识解释、结论和 CTA 是否形成闭环。
   - 检查口播说“只改一个变量”时，画面、声音、时长、顺序和响度是否真的只改该变量。
   - 检查“这里、这个、前面、我们看一下”等指代能否在对应时刻看到或听到真实内容。
   - 小改能够明确提高准确性或可执行性时，直接做成“分镜使用稿”，并在交付中用不超过 5 条说明改了什么。若改动会改变核心观点、案例对象或需要用户提供关键事实，集中问一个问题；其余部分继续完成。

3. **按剪辑事件拆分，不按标点机械拆分**
   - 一行完成一个清楚的观看任务，例如提出问题、完整播放 A 版、诊断原因、演示一个操作、回放结果或总结迁移。
   - 当主画面类型、声音状态、观众任务或情绪阶段发生变化时拆行。连续几句话服务同一画面和目标时可合并。
   - 口播必须按顺序完整覆盖。非口播的播放、停顿和黑场写进画面或声音设计，不伪装成主持人台词。

4. **重建可读的时间轴**
   - 时间连续、无意外重叠或倒退。正常中文教学口播先按约 3.5–4.5 个有效汉字/秒估算；开头短句可以略快，复杂概念和参数应更慢。
   - A/B 完整播放、操作录屏、停顿和结果回看要单独留真实时长。没有录音时标“预估”，不写精确到帧的伪确定时间。
   - 若模板原时间与字数明显不匹配，重做全表时间，不从错误时间点机械续写。

5. **填满九个字段**
   - 默认表头固定为：`镜头｜预估时间｜这一镜要完成什么｜画面｜参考图｜参考素材｜对应口播｜花字 / 屏幕信息｜声音 / 剪辑设计`。
   - 每一格都写可执行信息。无法确定的内容写清“待补什么、由谁提供、用来解决什么”，不留含糊空白。
   - 具体标准见 [field-guide.md](references/field-guide.md)。

6. **让剪辑设计服务教学**
   - 人物出镜承担问题、公式和总结；案例成片、时间线、波形、参数和操作承担证据与演示。
   - 每个知识点尽量形成“问题/错误 → 改一个要素 → 回放 → 解释差异 → 给操作方法”的小循环。
   - A/B 先分别完整播放，再解释，最后比较。核心是声音时，完整播放期间通常暂停口播；两版尽量同长度、同总响度，避免用“更响”冒充“更好”。
   - 使用转场、riser、impact、黑场、J-cut 或 L-cut 时说明目的。不要给每个切点都堆音效。

7. **做素材总清单与验收**
   - 去重汇总：需要实测、需要录屏、需要 AI 生成、需要搜索/下载、需要后期制作、用户已有/需要补充。
   - 核对口播全文覆盖、镜头编号、连续时间、素材状态、A/B 变量、字幕遮挡、车型/角色/空间连续性、音乐与音效授权。
   - 完整播放一次“关音乐版”或静音画面版，确认节奏不是只靠燃曲支撑；再用耳机与手机外放检查口播、发动机、环境声和强调音效的层级。

## 研究要求

脚本教授专业方法、提到具体软件/模型/平台能力、使用品牌案例或包含容易变化的事实时，要做一次针对性检索。优先官方文档、原始研究、创作者官方教育资料和一手访谈。将稳定的剪辑原则与本次推断、首轮试剪参数分开；没有权威统一数值时，明确写“建议起点，需按素材实测”。

不为每篇稿固定堆砌搜索数量。研究必须解决当前脚本的真实问题，例如验证功能、补足操作、判断实验变量或识别素材连续性风险。

## 文件交付

用户提供 Excel 模板时，保留工作表名称和字段顺序，补全或校正相邻内容，并改善实际影响使用的换行、列宽、行高和冻结表头。没有模板时，创建一个单工作表 `.xlsx`，使用上述九列，不额外造空白封面或重复说明页。

交付的 `对应口播` 使用已审定的“分镜使用稿”，不能遗漏或重复句子。聊天中简要给出必要的脚本调整、仍待用户补充的素材，以及飞书导入/覆盖步骤；不要把内部推理和自评分写入文件。
