# 博主认可样稿的写法

参考的是电商教程分镜的表达方式：口播是主线，画面说明简洁，素材清单直接，剪辑有发挥空间。镜头数量和具体案例根据本次口播决定。

## 常用表达

- 口播解释：`口播画面＋文字说明`，制作备注可写`无`。
- 工具教学：`（人物小窗）画面展示操作录屏`，制作备注写`视频素材：操作录屏`。
- 讲解加案例：`（人物小窗）画面展示知识点板书及案例`，备注列出需要的图片或视频。
- 同镜换画面：`（某句～某句）口播画面；（某句～某句）配套视频`。
- 模块演示：`不同模块拼合动画，形式自拟`。
- 结果回看：`复用前面的生成结果`。不另编素材编号。

## 短例

| 镜号 | 口播文案 | 画面描述 | 效果制作备注（剪辑过程中有不理解的可以写在这里标蓝） | 剪辑备注2（剪辑过程中有不理解的可以写在这里标蓝） | 提示词 | 一审结果（及修改意见） | 二审结果（及修改意见） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 真正能落地的商业设计，必须先做产品分析和整体规划。 | 口播画面＋文字说明 | 无 | | | | |
| 2 | 老规矩，提示词也都整理到文档啦！ | （人物小窗）画面展示文档 | 视频素材：文档录屏 | | | | |
| 3 | 接下来，我们就可以使用前面生成的套图制作营销海报啦！ | 口播画面＋套图展示 | 图片素材：复用前面的模特套图 | | | | |
| 4 | 这一张主视觉非常重要，它会决定后续整套电商设计的方向。包括配色、场景、光影、构图、字体以及整体品牌氛围。 | （这一张～方向）口播画面＋文字说明；（包括～氛围）（人物小窗）展示教学板书 | 图片素材：配色、场景、光影等示意图 | | | | |
| 5 | 再看效果： | 展示跟拍效果，口播后接A/B对比 | 视频素材：复用前面的普通跟拍和优化案例 | 播放对比时暂停口播 | | | |

这些短例只示范写法。实际工作保留当前用户口播，按其内容填写素材需求，提示词和审核列留空。学习原样稿的简洁程度；原样稿中的纯标题展示等无口播安排，在本工作流中并入相邻的口播行。
